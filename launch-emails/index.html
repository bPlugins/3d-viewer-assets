Launch Email Templates

25 ready-to-send emails for the launch of 3D Product Configurator for WooCommerce: teasers, launch day, feature deep dives, story emails, use cases and follow-ups. Each has one banner, one button and two links, and every claim matches the verified feature list (v1.1.0).

Before you send

  • Merge tags: {{first_name}}, {{launch_date}}, {{sender_name}}, {{unsubscribe_url}} and {{company_address}}. Swap them for your email tool's syntax (Mailchimp uses *|FNAME|*, for example) and set a fallback for first name, like "there".
  • Images: the previews use the WebP screenshots already on bplugins.com. Classic Outlook on Windows doesn't show WebP. JPG copies are in the images/ folder next to this file. Click Use repo JPGs (or paste your own folder URL) and Copy HTML / Download will use the JPGs.
  • Licensing: the emails say "3D Viewer Pro plan or higher". The live hub page still says "Included in the 3D Viewer Max plan", so fix one or the other before sending.
  • Tracking: bplugins.com links carry utm_campaign=wc3d-launch and utm_content=e03-button style tags. YouTube links don't.
  • Test: send each one to Gmail, Apple Mail and Outlook first. The button has an Outlook (VML) fallback; the preheader is hidden text at the top of the body.
